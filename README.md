# TERSİNE AKAN ÇAY NEHRİ

## Resmî Bildiri

Bu depo, çayın doğal akışını reddeden, yerçekimine itiraz dilekçesi veren ve zamanı demlikte tersine çevirmeye çalışan bir protokoldür.

Proje **bilimsel değildir**. Ancak resmi görünmek için elinden geleni yapar.

## Neden var?

Çünkü düz akan çay sıradandır. Tersine akan çay ise:
- bardaktan demliğe kaçar
- şeker çözülmeden önce geri gelir
- sohbeti başa sarar
- çaycıya “daha demlemedim” dedirtir

## Kurulum

```bash
python3 cay.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz sabır.

## Kullanım

Script çalıştığında çay nehri tersine akmaya başlar. Her adımda resmi bir tutanak düşer. Program kendi kendine durmaz; çünkü tersine akan nehir durmaz, sadece utangaçlaşır.

Durdurmak için `Ctrl+C` basın. Bu, protokole göre “acil müdahale” sayılır.

## Sıkça sorulmayan sorular

**Bu çay içilir mi?**  
Hayır. Bu çay felsefidir.

**Şeker kaç küp?**  
Zaman tersine aktığı için şeker henüz eklenmemiştir ve zaten erimiştir.

**Neden Türkçe?**  
Çünkü çay Türkçe konuşur.
